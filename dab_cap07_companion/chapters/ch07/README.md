# Chapter 7 · Exploratory Data Analysis

Run the whole chapter session from the repository root:

    python chapters/ch07/run_session.py

This executes `listings/07_*.py` in order in one shared namespace (like a notebook), writes each
listing's printed output to `outputs/`, and saves Figures 7.1–7.4 to `figures/`.

| Folder | Contents |
|---|---|
| `listings/` | Listings 7.0–7.18 |
| `outputs/` | Printed output of each listing, plus `findings_log.csv` |
| `figures/` | Figures 7.1–7.4 |
| `exercises/` | Exercise briefs 7.1–7.3 |
| `solutions/` | Exercise solutions and `ch07_answers.md` |
| `tests/` | `pytest chapters/ch07/tests` checks the headline numbers |
