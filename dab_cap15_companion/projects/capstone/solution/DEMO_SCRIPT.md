# Three-minute demo script

1. (20 s) The problem: an analyst gets a dataset and needs a model and a recommendation she can defend.
2. (30 s) **Data**: open the Kwacha Basket sample database, choose `customer_churn`, show the read-only SELECT.
3. (20 s) **Prepare**: point out the change log; nothing is changed silently.
4. (20 s) **Explore**: recency by province box plot.
5. (40 s) **Model**: target `churned`; AUC about 0.78 cross-validated; move the threshold and watch precision and recall trade off.
6. (40 s) **Insights**: open "What will be sent": coefficients and metrics only, no customer rows. Generate; point to the verification banner and the AI-generated label.
7. (10 s) **Report**: download the HTML.
8. (20 s) Close: what you would build next (model comparison; scheduled refresh) and what the tests check.
