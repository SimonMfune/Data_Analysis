# Chapter 15 exercises

- **Acceptance** Complete the workspace in `projects/capstone/starter`. It must work with the Kwacha Basket
  sample database and with one other dataset; model metrics must update live; AI recommendations must cite
  only verified figures and be labelled as AI-generated; and the app must be deployed at a public URL with no
  secrets in the repository. Submit the URL, the repository link and a 300-word portfolio write-up.
- **Extension** Add one of: model comparison (two models side by side on the same split), scheduled data
  refresh, or a natural-language query box that turns a question into a SELECT with the Chapter 4 schema and
  the read-only guard of Section 15.3.
