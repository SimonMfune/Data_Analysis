# Chapter 1 — Introduction to Data Analysis and Types of Data

Chapter 1 needs no code. You only need the data file and the worksheet.

| File | Use |
|---|---|
| `../../data/clean/kb_customers_sample.csv` | The 200-customer file for Exercise 1.1 |
| `exercises/ex1_1_data_types_worksheet.csv` | Blank worksheet: one row per column to classify |
| `solutions/ex1_1_data_types_solution.csv` | Model answers for Exercise 1.1 (try first!) |
| `solutions/ch01_answers.md` | Answers to Check Your Understanding, review questions and Exercise 1.2 |
| `figures/ch01_figures.py` | Script that draws Figures 1.1 and 1.2 |

Open the CSV files in Excel, Google Sheets or VS Code. If Excel shows phone numbers as `2.60961E+11`,
that is Excel converting a label to a number — exactly the trap described in Section 1.4.
